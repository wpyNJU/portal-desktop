# Portal Desktop 1.1.0

相较 v0.1.7 的更新：

- Being 语音通话：顶栏新增通话入口，通过豆包语音网关与 Being 实时对话；首次使用时对齐助手身份、称呼与偏好。
- 后台查询与报告：语音中需要 Being 处理的问题在后台执行，结果按最新请求优先播报，打断后保留播放进度。
- 连接恢复：接通时不再重放历史任务提示；已被 Agent 接收的回复可恢复，失败原因会持久保存并与当前查询结果区分。
- 语音 Web 版：`npm run package:voice-web` 生成独立的移动端通话包，附带网关、部署示例与交互流程文档。

安装包说明：

- Windows x64：NSIS 安装包与 ZIP 由 CI 构建。
- macOS Apple Silicon：本地构建，使用临时签名（未使用 Developer ID），首次打开需在“访达”中右键选择“打开”；应用内的 macOS 自动升级校验不适用于此版本，请手动下载安装。
