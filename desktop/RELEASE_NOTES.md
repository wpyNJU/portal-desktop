# Portal Desktop 1.1.3

- 修复普通问题被“我确认下”等过渡语抢占、字幕已出现却不播放答案的问题。
- 查询过渡支持常见消息、任务进展和部分上下文承接问法；按音色缓存短句音频，同一轮不重复接话。
- 简化豆包工具参数，减少嵌套参数生成错误引发的无效重试；请求按 ID 跟踪，不按正文合并。
- Being 同一会话支持多个请求合并返回：共享回复只播一次，按明确覆盖关系更新事项，未确认的事项继续保留。
- 修复录音仍上传但识别迟迟不结束时的无声等待，可恢复语音连接并保留后台任务。
- 任务列表隐藏内部共享回复记录，补充合并回复、恢复、播放优先级、缓存和任务身份回归测试。

语音网关改动已独立部署。客户端与网关源码均包含在本仓库；工具耗时仍受上游和网络影响，测试中的单次时延不代表所有通话。

安装包由 CI 在 Windows x64、macOS Apple Silicon 和 Intel 分别构建。Mac 使用临时签名，未使用 Apple Developer ID 或公证，首次打开可能需要在系统设置“隐私与安全性”中允许。此包不支持当前应用内自动升级校验，请手动下载安装新版本。云端语音网关需独立部署。
