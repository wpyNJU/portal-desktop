# Portal Desktop 1.1.1

- Mac 通话采用左右布局，保留聊天并展示通话界面。
- 优化插话停播、音频队列和播放确认；缩减历史加载，避免历史任务刷屏。
- 完善后台任务状态同步、查询身份与复用，区分追问具体内容和续读旧报告。
- 简短接话与查询并行，播报具体查询主题；修复部分结果和完成状态不同步的问题。
- 增加语音链路诊断与回归测试。

安装包由 CI 在 Windows x64、macOS Apple Silicon 和 Intel 分别构建。Mac 使用临时签名，未使用 Apple Developer ID 或公证，首次打开可能需要在系统设置“隐私与安全性”中允许。此包不支持当前应用内自动升级校验，请手动下载安装新版本。云端语音网关需独立部署。
